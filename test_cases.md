# ERDS test cases

1. **Short theory assignment:** Ask only for relevant missing title-page details, use standard template if none is supplied, cite sources, generate PDF.
2. **Uploaded assignment sheet:** Extract the instructions first; do not ask the user to repeat visible details.
3. **Major project with no results:** Mark implementation/results as pending or proposed; never invent measurements.
4. **Group project:** Include all supplied student names; ask for missing members only if the cover page requires them.
5. **College template provided:** Follow the template over the default professional template.
6. **No web access:** Disclose that live research was not performed; request sources or provide a clearly limited draft.
7. **Diagram requirement:** Generate an appropriate labeled diagram or provide diagram source; do not fabricate circuit connections.
8. **PDF conversion unavailable:** Preserve DOCX and report that PDF conversion failed; do not claim a PDF exists.
9. **Missing guide name:** Ask if relevant; allow skip and leave blank/omit.
10. **Citation mismatch:** Ensure in-text citations and reference list are cross-checked.
