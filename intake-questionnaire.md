# Intake questionnaire

## Required checks before finalization
Ask only for missing, relevant details. Do not ask users to repeat details found in the prompt or uploaded assignment brief.

### Student / institution
- Student name(s)
- College/university
- Department/engineering branch
- Roll number(s), only if needed
- Academic year/semester, if needed
- Subject/course and faculty, if needed

### Project
- Exact title
- Guide/supervisor name, if relevant
- Individual or group project
- Group members and roles, if relevant
- Project status: proposed, in progress, implemented, or tested

### Requirements
- Assignment brief/rubric/template
- Document type and expected length
- Required sections
- Citation style, if specified
- Required visuals, equations, code, circuit, or results
- Submission deadline, if relevant
- Desired output: PDF (default), DOCX, PPTX, diagrams, or combination

## Ask efficiently
1. Inspect supplied files first.
2. Group questions into one short form.
3. Distinguish essential from optional fields.
4. If no college template exists, say ERDS will use a suitable professional engineering template.
5. For complex work, ask approval of the outline before writing the full report.
6. Do not block progress for optional details; leave a clearly labeled placeholder or omit the field.
