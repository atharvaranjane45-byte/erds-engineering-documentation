# Academic writing guide

- Write clear, natural, technically accurate prose suitable for the stated academic level.
- Define abbreviations and technical terms on first use.
- Explain concepts in a logical order: definition, principle, working, example, strengths/limitations, application.
- Use active voice when it improves clarity; use formal academic tone without unnecessary complexity.
- Avoid repetitive filler, generic claims, and unsupported superlatives.
- Use equations with defined variables and units.
- Present algorithms in steps or pseudocode when useful.
- Explain code rather than dumping long unexplained blocks.
- Do not impersonate the student or fabricate first-person experiences.
- Do not claim the student built, tested, surveyed, measured, or observed anything unless supplied evidence supports it.
- Use “proposed,” “expected,” or “to be measured” for work not yet performed.
- Write for learning and viva preparation; include short key-takeaway sections when useful.
