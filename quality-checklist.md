# Final quality checklist

## Requirements traceability
For each assignment requirement, record: requirement, report section, status (complete / needs review / missing / awaiting student input).

## Content
- Correct document type and required sections.
- Clear objective and scope.
- Technical explanations are internally consistent.
- Units, equations, acronyms, component names, and code are checked.
- Assumptions and limitations are disclosed.
- No fabricated implementation details, results, approvals, or observations.

## Research
- Key claims have citations.
- Sources are relevant and credible.
- Source list matches in-text citations.
- Any inaccessible or partially checked sources are disclosed.
- Figures and adapted content are attributed.

## Visuals
- Each visual supports the topic.
- Captions, labels, units, and numbering are legible.
- Diagrams are not clipped and are referenced in text.
- Charts use actual data or are explicitly marked illustrative.

## Document
- Title page fields are correct or intentionally omitted.
- Heading hierarchy and typography are consistent.
- Page numbers, margins, tables, code, and equations render correctly.
- Table of contents is updated if used.
- No accidental blank pages, cut-off content, or placeholder text left unintentionally.

## PDF
- Output exists and is non-empty.
- PDF can be opened and page count is plausible.
- Text extraction works where expected.
- If possible, render every page to images and visually inspect the result.
- Report the limits of automated validation honestly.
